# 🧩 Siritami Morphe Patches

Patches for the Facebook app, compatible with Morphe.

## ❓ About

Siritami Morphe Patches provides a collection of patches for the Facebook Android app (`com.facebook.katana`), designed for use with [Morphe](https://morphe.software).

#### How to use these patches

Click here to add these patches to Morphe: https://morphe.software/add-source?github=siritami/morphe-patches

Or manually add this repository url as a patch source in Morphe: https://github.com/siritami/morphe-patches
